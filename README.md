# SHINJICASE — ケース面接 × 警察ドラマ風プラクティス（モック）

米国警察捜査ドラマの体裁でケース面接を練習するアプリの **最小モック** です。  
本リポジトリでは **フェーズ iii「PRIME SUSPECT（容疑者特定）」のみ** が動きます。他フェーズはナビのプレースホルダです。

## これは何か

プレイヤーは捜査ボード上の候補カードから最大 **3** 名をプライム容疑者としてピン留めし、一人ずつ短い動機（仮説）を書いて CAPTAIN（AI面接官の代用・スクリプト）に提出します。CAPTAIN のチャレンジ後にピンや動機を直して再提出すると **REVISE BONUS** が加算されます。

サンプルケースは架空の「郊外ガソリンスタンド売上急減」です。

## ケース面接 ↔ 警察テーマ対応（フェーズ iii）

| ケース面接 | 本アプリ（警察ドラマ） |
| --- | --- |
| ⅲ ボトルネック特定 | **PRIME SUSPECT（容疑者特定）** |
| 論点・仮説ノード | 候補カード / ノード |
| 主因の絞り込み（最大数） | 赤ピン留め（最大 3） |
| なぜそれがボトルネックか | 動機 / 仮説の一行メモ |
| 面接官の突っ込み | **CAPTAIN** のチャレンジ質問 |
| 修正して再回答 | **REVISE BONUS**（+スコア） |

将来の全体フロー（未実装）: BRIEFING → EVIDENCE → **PRIME SUSPECT** → OPERATION → WARRANT

## 動かし方

```bash
npm install
npm run dev
```

ブラウザで表示された URL（通常 `http://localhost:5173`）を開いてください。

```bash
npm run build   # 本番ビルド
npm test        # ロジックスモークテスト
```

## このモックでできること

1. 候補カード一覧の表示（ハードコードのサンプルケース）
2. クリックでプライム容疑者にピン留め / 解除（最大 3、赤リング）
3. ピン留めした容疑者ごとに動機（一行）入力
4. CAPTAIN に提出 → スクリプトによるチャレンジ（空・短い動機・人数・理想どおり、で文言変化）
5. チャレンジ後に編集して再提出 → REVISE BONUS 加算
6. 簡易 SCORE / REVISE BONUS / PRIMES 表示
