# 回答3：朝の通勤客を最優先に、住民はスモールスタート

## 許容解（GHOST）

パターン3：朝の通勤客と住民の需要（95点）

- **前提**：特定の1店舗。都市部の混在エリア。主な客層は通勤客と住民。依頼人はFC加盟店
- **構造化**：売上＝客数×客単価。通勤客は朝の朝食需要が多い。住民は朝昼夜にまんべんなく来る
- **ボトルネック**：朝の通勤客の時間の制約と単価の低さ、住民需要を取り込めていないこと
- **施策**：朝のコーヒーと弁当などのセット（単価）、レジの効率化（時間の制約）、日用品の拡充と小容量のラインナップ（住民）

## 完全解（GOD）

**前提**：特定の1店舗。都市部の混在エリア。客層は通勤客と住民。依頼人はFC加盟店

**構造化**
```
売上 = 客数 × 客単価
  ├ 通勤客：朝に集中。昼は会社、夜は自宅や外食で来店が限られる   〔質疑6〕
  ├ 住民：一日を通して需要が見えにくい
  ├ 客数 ← 来店頻度（セット販売や品揃えの拡充で伸ばせる）       〔質疑4〕
  └ 客単価 ← 1回あたりの点数（朝の通勤客で最も伸びしろがある）   〔質疑3〕
```
- 最も解くべき課題：**朝の通勤客の時間の制約と単価の低さ**〔質疑1〕

**施策**
| 施策 | 中身 |
|---|---|
| A 朝のセット | コーヒーと弁当などのセットで、朝ごはんがすぐ揃うようにする。既存の商品で始められる〔質疑1〕。顧客のロイヤリティも高め、来店頻度にも効く〔質疑4〕 |
| B レジの効率化 | 朝の時間の制約に応える |
| C 日用品・小容量の拡充 | 住民の需要に応える。新たな投資が必要なので中長期の施策〔質疑1〕 |
| D 八百屋的な生鮮ラインナップ | 2〜3年の時間軸ならスモールスタートで始める〔質疑2〕。スーパーから客を引き込み、来店頻度を上げる〔質疑4〕 |

**優先順位**：通勤客の施策が最優先。2〜3年の時間軸にしても変わらない〔質疑1・2〕。
