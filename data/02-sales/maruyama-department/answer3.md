## 完全解（GOD）

**前提**
- 対象：地方中核都市の駅前にある老舗百貨店
- 時間軸：5年
- ゴール：売上向上。利益は「値引きで体力を削らない」という制約条件として扱う〔質疑1〕

**現状**
| 強み | 弱み |
|---|---|
| 駅前という立地 | 若い世代を取り込めていない |
| 長年の常連客 | ネット販売への対応が遅れている |
| 上位顧客との関係 | 売場の使い方が今の消費行動に合っていない |
| 地元での信頼 | |

- 売上減少の主因は客数の減少。常連客は高齢化で自然に減っていき、単価もすでに高いので伸びしろが小さい〔質疑2・3〕

**構造化**
```
売上 = 客数 × 客単価
  └ 客数 = 既存客（自然減）＋ 新規客                       〔質疑2〕
       └ 新規客 = 駅の通過人数 × 入館率 × 高単価売場への転換率   〔質疑3・4〕
```
- 狙う箱：駅利用者の入館率と、入口から高単価売場への転換

**施策**
| 施策 | 中身 |
|---|---|
| A 来て楽しめる場 | 飲食やイベントで、入りやすい入口を作る |
| B 集客テナント | 賃料目的ではなく、館全体の客数を増やす手段として入れる〔質疑1〕 |
| C 既存の売場と上位顧客 | 売場と品揃えの見直し、上位顧客との関係強化 |
| D 転換の仕組み | 決済時に自動でポイントがたまる会員の仕組みにし、誕生日や記念日に上の売場を案内する〔質疑4・5〕。飲食や雑貨のスタッフが贈答需要を拾い、高単価売場の担当者へつなぐ〔質疑4〕 |
| E 値引きに頼らない関与 | 会員への先行情報と先行体験。荷物の一時預かりや休憩スペースの優先案内〔質疑6〕 |
