## 合格の条件・許容分解・不可・突っ込み（共通）

## 合格の条件

| # | 要素 | 合格ライン |
|---|---|---|
| 1 | 前提 | 1店舗かどうか、立地、客層、期間のうち2つ以上を確認するか、自分で置く |
| 2 | 分解 | 売上を下の表のいずれかで分解し、動かせない要素を明言する |
| 3 | 絞り込み | 立地と客層から、狙う箱を1つに絞る理由を言う |
| 4 | 施策 | 狙った箱にひも付いた具体策がある |
| 5 | 話し方 | 結論から話す |

**許容する第1分解**

| 分解 | パターン |
|---|---|
| 客数×客単価（×頻度） | 1・3 |
| 商圏人数×選択率×レジの回転率×客単価 | 2 |
| 通過人数×来店割合×客単価 | 4（駅前と置いた場合） |
| 来店客数×購入率×客単価（購入率は動かさない） | 5 |
| 近隣住民数×食事の回数×選択率×客単価 | 6 |

**許容するボトルネック**

| ボトルネック | パターン | 条件 |
|---|---|---|
| 朝の通勤客の客単価 | 1・3 | 客数が多いのに単価が低い、という根拠 |
| 住宅客の需要の取りこぼし | 2・3 | 混在エリアなのに品揃えがオフィス寄り、という根拠 |
| 来店割合 | 4 | 駅前で通過人数が大きい、という前提 |
| 夕方の住民の買上点数 | 5 | 帰宅途中にまとめて買いたい、という根拠 |
| 競合から取り込める選択率 | 6 | 既存客の需要はすでに取り切っている、という根拠 |
| レジの回転率 | 1・2・3 | 2番手として。単独で最重要に置くなら、待ち時間による取りこぼしの根拠が必要 |

**不可とするもの**：商圏人数や通過人数を増やすことを主軸にする／多店舗展開や本部の施策（対象外）／狙う箱にひも付かない施策

## コンビニの突っ込みパターン（6件から）

| パターン | 例 |
|---|---|
| 実現性・制約 | 朝のピークにセット特典を回せるか（完全解1） |
| 課題を1つに絞る | 最も解くべき課題は何か（1・2・3） |
| 二択・優先順位 | 点数と頻度のどちらか、どの施策から始めるか（2・3・5） |
| 前提への反証 | 客層が固定なら頻度も伸びないのか（3）、最も不確かな前提は（4） |
| 純増かどうか | セットへの置き換えにすぎないのでは（5） |
| リスク | 個人情報、推定の誤り（5） |
| 効果の測り方 | 表示しなくても買っていた分をどう切り分けるか（5） |
| 売場面積のトレードオフ | 棚を削ると既存売上が落ちないか（6） |
| 価格差を超える理由 | スーパーより割高でも選ばれるか（6） |
| 別の方向性 | 既存の打ち手が使えないなら何をするか（1・2） |
