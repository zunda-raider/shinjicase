# お題：地方百貨店の売上を向上させる生き残り戦略を提案してください

最初の5分の発表を「許容解（GHOST）」、質疑での回答まで盛り込んだものを「完全解（GOD）」として6人分まとめたもの。完全解の中で、質疑から加えた部分には〔質疑n〕と付けている。数字は質疑で話された範囲だけを入れ、明らかな言い間違いだけ直している。

---

# 許容解（GHOST）：最初の5分でここまで言えれば合格圏

## 必須の要素

| # | 要素 | 合格ライン |
|---|---|---|
| 1 | 前提 | 立地、顧客層、期間のうち2つ以上を確認するか、自分で置く。ゴールを置く（数値が望ましい） |
| 2 | 分解 | 売上を、下の表のいずれかの形で分解する |
| 3 | 絞り込みの理由 | どの箱を狙うかを、立地・顧客・競合から理由づける |
| 4 | 施策 | 狙った箱にひも付いた具体策を2つ以上出す |
| 5 | 話し方 | 結論から話す |

## 許容する第1分解

| 分解 | 使った人 |
|---|---|
| チャネル別：店頭＋外商＋ギフト（＋催事） | 1人目 |
| 客数×客単価 | 2・3・5人目 |
| 客数×購買率×客単価（平日／休日×時間帯で内訳） | 4人目 |
| 来店客数×購買率×客単価×来店頻度 | 6人目 |
| カテゴリ別：衣料品／食品／化粧品／その他 | 5人目 |

## 許容する主軸と、絞り込みの理由

| 系統 | 主軸 | 理由として言えていればよいこと |
|---|---|---|
| 客単価を深掘りする | 外商、ギフト、法人 | 人口減少と競合で客数は伸ばしにくい。百貨店の信頼（品質保証、包装、配送）が最も活きる |
| 来店の理由を作る | 食品、催事、イベント、テナント | 百貨店に行く理由がない／平日の日中が空いている。入口から化粧品・雑貨などへの回遊につなげる一言がある |

**不可とするもの**
- 衣料品でSPAやECと価格で正面から勝負する
- 不動産の賃料収入を「売上向上」として扱う
- 値引きを中心に据える

## 6パターンの到達度

| パターン | 主軸 | 到達度 | 足りない点 |
|---|---|---|---|
| 1 食品・ギフト・外商 | 客単価 | ◎ | — |
| 2 外商の深掘り | 客単価 | △ | 具体策の前で終了 |
| 3 強み・弱みから3方向 | 方向性のみ | △ | 比較と結論の前で終了 |
| 4 平日の朝・昼にイベント | 客数 | ○ | 購買への転換が弱い |
| 5 地域の上質な生活拠点 | 頻度→回遊 | ◎ | — |
| 6 食品と催事が起点 | 頻度→回遊 | ○ | 回遊する客層が未特定 |

# 完全解（GOD）（6人分）

## 完全解1：食品・ギフト・外商に集中

**前提**
- 対象：1店舗
- 売上の定義：店頭販売＋外商＋ギフト＋催事
- ゴール：3年で売上を100から120に

**現状**
- 人口減少で、来店客数を大きく伸ばすのは難しい
- 品揃えや価格では、スーパーやECに勝てない
- 本質的な課題は**体験価値の低下**。「行く理由」「送る理由」「相談する理由」が弱くなっている〔質疑4〕
- 若年層との接点が弱い

**構造化**
```
売上 = 店頭（来店客数×購入率×客単価×来店頻度）＋ 外商 ＋ ギフト ＋ 催事
  ├ 用途別：自家用／ギフト／法人                〔質疑1・2〕
  └ チャネル別：来店／来店しない購入（電話注文・配送） 〔質疑1〕
```
- 狙う箱：ギフト・法人という用途への拡大、来店しない購入、来店時の体験価値

**施策**
| 施策 | 中身 | 見込み |
|---|---|---|
| A 食品・地域・ギフト | 地元の商品を、包装、配送、法人対応までまとめて提供する。日常の買い物ではなく、歳暮、中元、香典、帰省土産など単価の高い用途に寄せる〔質疑1〕。食品売場を試食や週替わりの地域フェアで「試せる場所」にし、ギフト売場に用途別の相談カウンターを置く〔質疑5〕 | ＋8 |
| B 外商 | 高齢富裕層の電話注文と配送〔質疑1〕。地元企業の周年行事、退職祝い、手土産。商工会、金融機関、自治体、病院、学校と連携し、季節ギフトのカタログとまとめ注文の窓口を作る〔質疑2〕。外商顧客向けの試食会を店舗で開く〔質疑5〕 | ＋7 |
| C 催事 | 物産展、地元食品フェア、季節イベント | ＋5 |
| D 若年層（将来への投資） | 全面転換ではなく補完として、地元カフェ、スイーツ、雑貨、ポップアップ、学生企画で接点を作る。LINEやSNSで催事情報とギフト予約を発信する〔質疑6〕 | — |

**伸ばせる根拠**：値上げではなく、ギフト化、法人化、来店しない購入の拡大で伸ばす。個人の購買余力だけに頼らない〔質疑1〕。

## 完全解2：外商の深掘りで客単価を最大化

**前提**
- 対象：地方中核都市の駅前にある老舗百貨店1店舗
- 時間軸：5年
- ゴール：黒字化。必要な増収を5〜10億円と置く〔質疑1〕
- 現状の数字：売上150億円、来店客数400万人、客単価3,750円
- 収支：固定費が重く、ほぼ均衡からやや赤字
- 競合：モール、専門店、EC、SPA

**現状**
- 客単価が一般の小売店並みで、百貨店の強みが数字に出ていない
- 客数を増やす打ち手は、モール、SPA、ECと正面からぶつかるうえ、人口も減っている

**構造化**
```
売上 150億円 = 客数 400万人 × 客単価 3,750円
  ├ 一般売場 112.5億円
  └ 外商 37.5億円（売上の25%）= 外商顧客 5,000人 × 年間購入額 75万円   〔質疑2〕
       ├ 外商顧客数 = 既存 ＋ 新規の4つの出どころ                       〔質疑3〕
       └ 年間購入額 ← 純増する4つのカテゴリ                             〔質疑4〕
```
- 狙う箱：外商顧客の年間購入額と、外商顧客数

**施策**
| 施策 | 中身 |
|---|---|
| A コンシェルジュ型の外商 | 家族構成やライフイベントの予定を把握したうえで提案する〔質疑5〕。純増させる購入は、これまで店で買っていなかった高額品、ライフイベント（リフォーム、贈与）、経営する法人としての需要、都市部やECに流れていた高級品・限定品の取り戻し〔質疑4〕 |
| B 外商化する対象 | ①一般売場の優良顧客（すぐ着手）、②地元の事業オーナーや開業医、③金融機関や士業からの紹介（②③は1〜2年）、④県外に住む地元出身者（3〜5年）〔質疑3〕 |
| C 選ばれる理由 | 個人に合わせた目利きと提案、地元ですぐに失敗なく済ませられること、地元での信用と格式〔質疑5〕 |
| D 組織づくり | 1年目は既存顧客で試して型にする。2〜3年目はマニュアル化して横展開する。4〜5年目に組織に定着させる〔質疑6〕 |

**試算**：外商37.5億円に対して、年間購入額＋10%で＋3.75億円、外商顧客数＋10%で＋3.75億円。合計＋7.5億円で、5〜10億円の幅に収まる。2〜3年目は目標の半分程度〔質疑2・6〕。

## 完全解3：駅利用者を呼び込み、高単価の購買につなげる

**前提**
- 対象：地方中核都市の駅前にある老舗百貨店
- 時間軸：5年
- ゴール：売上向上。利益は「値引きで体力を削らない」という制約条件として扱う〔質疑1〕

**現状**
| 強み | 弱み |
|---|---|
| 駅前という立地 | 若い世代を取り込めていない |
| 長年の常連客 | ネット販売への対応が遅れている |
| 上位顧客との関係 | 売場の使い方が今の消費行動に合っていない |
| 地元での信頼 | |

- 売上減少の主因は客数の減少。常連客は高齢化で自然に減っていき、単価もすでに高いので伸びしろが小さい〔質疑2・3〕

**構造化**
```
売上 = 客数 × 客単価
  └ 客数 = 既存客（自然減）＋ 新規客                       〔質疑2〕
       └ 新規客 = 駅の通過人数 × 入館率 × 高単価売場への転換率   〔質疑3・4〕
```
- 狙う箱：駅利用者の入館率と、入口から高単価売場への転換

**施策**
| 施策 | 中身 |
|---|---|
| A 来て楽しめる場 | 飲食やイベントで、入りやすい入口を作る |
| B 集客テナント | 賃料目的ではなく、館全体の客数を増やす手段として入れる〔質疑1〕 |
| C 既存の売場と上位顧客 | 売場と品揃えの見直し、上位顧客との関係強化 |
| D 転換の仕組み | 決済時に自動でポイントがたまる会員の仕組みにし、誕生日や記念日に上の売場を案内する〔質疑4・5〕。飲食や雑貨のスタッフが贈答需要を拾い、高単価売場の担当者へつなぐ〔質疑4〕 |
| E 値引きに頼らない関与 | 会員への先行情報と先行体験。荷物の一時預かりや休憩スペースの優先案内〔質疑6〕 |

## 完全解4：平日の朝・昼に地域イベントで来店の目的を作る

**前提**
- 顧客層：近隣の中高年層が中心。若年層とファミリーは減少
- 競合：モール、専門店、EC、SPA
- 時間軸：5年
- 投資：制約なし

**現状**
- 休日は施策がなくても買い物目的の客が来る。平日は目的のある客しか来ない〔質疑1〕

**構造化**
```
売上 = 客数 × 購買率 × 客単価
  ├ 客数 = 来店客数 × 来店頻度（平日／休日 × 朝／昼／夜）
  ├ 購買率 ← イベント参加 → 館内の回遊 → 購入              〔質疑2〕
  └ 客単価 = 平均買上点数 × 商品単価
```
- 狙う箱：平日の朝・昼の客数と、イベント来場者の購買率

**施策**
| 施策 | 中身 |
|---|---|
| A 地域コミュニティ向けイベント | 平日の朝・昼に開き、地元ならではの体験価値で差別化する |
| B 購買までの導線 | 当日限定で館内の複数店舗で使えるクーポン、フロアを回るスタンプラリー、一定額以上の購入で限定特典。イベントは集客の入口と位置づける〔質疑2〕 |
| C 体験価値への移行 | クーポンは初回来店のきっかけに限定する。その後は工芸品の実演販売、生産者との交流会、百貨店ならではの接客でリピートにつなげる〔質疑3〕 |
| D まとめ買いセール | 買上点数を上げる |
| E テナントの見直し（中長期） | POSデータやアンケートで需要を分析し、地元の人気店、体験型テナント、飲食店に入れ替える〔質疑4〕 |

**順番**：短期の集客を優先する。テナントの入れ替えは投資と調整に時間がかかり、集客で得たデータをもとに見直したほうが判断が客観的になるため〔質疑5〕。データの偏りは、地域住民へのアンケート、競合施設の利用状況、人口構成のデータで補い、ポップアップストアで売れ行きを試してから本格的に入れ替える〔質疑6〕。

## 完全解5：「地域の上質な生活拠点」への転換

**前提**
- 対象：地方中核都市の駅前の1店舗。周辺の商業集積は弱まりつつある
- 顧客層：中高年が中心。若年層とファミリーは減少
- 売上：ピーク時250億円から150億円に減少
- 売上構成：衣料品35%、食品30%、化粧品15%、その他20%
- ゴール：5年で売上を180億円（＋30億円）に戻して黒字化

**現状**
- 売上減少の主因は、衣料品目的の来店の減少
- 食品と化粧品には百貨店の強みが残っている

**構造化**
```
売上 = 客数 × 客単価
  ├ カテゴリ別：衣料品35／食品30／化粧品15／その他20
  └ 客数 = 既存の中高年 ＋ 近隣のファミリー ＋ 法人・地域事業者   〔質疑2〕
```
- 狙う箱：食品での来店頻度、他カテゴリへの回遊、衣料品の再生

**施策**
| 施策 | 中身 |
|---|---|
| A 食品の強化 | 安さや品揃えの広さではなく、「少し良い日常」と贈答に絞る。地元名店の惣菜、落ち着いて選べる手土産、百貨店品質の弁当や和菓子、生鮮ギフト。老舗の曜日限定出店、週替わり惣菜、地域フェス、予約制のギフト相談で毎週変化を作る〔質疑1〕。来店時に化粧品や雑貨へ回遊させる |
| B 衣料品を縮小しながら再生 | 低単価で回転の速い日常衣料は縮小する。中高年が「失敗したくない」衣料（冠婚葬祭、旅行、同窓会、仕事用、体型の変化に合う服）を、予約制のスタイリング相談と化粧品・雑貨とのセット提案で再生する〔質疑5〕。店頭は試着と相談に絞り、取り寄せ、予約販売、後日受け取り、配送で売上機会を保つ〔質疑6〕 |
| C ファミリー | 惣菜、スイーツ、地域祭事、子どもイベントを組み合わせ、月1回の来店を狙う〔質疑2〕 |
| D 法人（B2B2C） | 贈答市場の拡大ではなく、地域企業の購買を百貨店に集約する。対象は、残っている贈答需要、会議・研修・祝賀の弁当や手土産、周年行事や採用イベントの記念品〔質疑3〕。店頭の食品・ギフト売場の商品、在庫、包装、人員で提供し、受け取りを店頭にする。法人の従業員向け優待で個人の来店にもつなげる〔質疑4〕 |

**試算**：3つのセグメントの積み上げで＋30億円。うち法人で15億円程度を狙う〔質疑2〕。

## 完全解6：食品と催事を起点に、日常的に来店される場所へ

**前提**
- 対象：地方中核都市の駅前にある老舗百貨店1店舗
- 顧客層：中高年が中心。若年層とファミリーは減少
- 売上構成：衣料品35%、食品30%、化粧品15%、その他20%
- 時間軸：5年

**現状**
- 本質的な課題は、百貨店に行く明確な理由がなくなっていること
- 衣料品は正面から伸ばすのが難しい
- 食品は購入頻度が高く、駅前の行き帰りとも相性が良い
- 食品は単価と粗利が低いので、あくまで入口として使う〔質疑1〕

**構造化**
```
売上 = 来店客数 × 来店頻度 × 購買率 × 客単価
  └ 客層別：休日の中高年（主役）／観光客／休日のファミリー／平日の仕事帰り（回遊の対象外）  〔質疑2・3〕
```
- 狙う箱：来店頻度と、食品から化粧品・雑貨・ギフトへの回遊

**施策**
| 施策 | 中身 |
|---|---|
| A 食品を上質な日常の拠点に | 地元の上質な食品の試食、季節催事、人気のベーカリーやスイーツ店の誘致、駅利用者向けの高単価な駅弁。スーパーと同じ食品ではなく、人気店の惣菜や手土産スイーツなどの高付加価値品に絞る〔質疑1〕 |
| B 回遊の仕掛け | 食品フロアから化粧品・服飾雑貨へつながる動線、催事と化粧品・雑貨のキャンペーン連動、上層階で使えるクーポン〔質疑1〕 |
| C 客層ごとの回遊 | 休日の中高年は化粧品カウンセリングと贈答売場へ。観光客は食品ギフトから包装サービス、雑貨、服飾へ。休日のファミリーは子ども向けイベント、カフェ、雑貨売場へ〔質疑2・3〕 |
| D 時間軸のフェーズ | 1年目は中高年への接客を強化し、来店頻度と客単価を上げて原資を作る。3年目以降はその収益で、親子向け催事、スイーツ、子ども向けイベントによる若年層・ファミリーの導線を作る。5年後に若年層・ファミリーが増えていなければ、生き残りとしては不十分と判断する〔質疑4〕 |
| E 百貨店ならではの勝ち筋 | 品揃えの広さではなく、地元での信頼感、食品・ギフト・化粧品を横断した生活シーン全体での提案、探す手間を減らす接客〔質疑5〕 |

---

完全解は、1・2人目が「客単価を深掘りする」系統、3〜6人目が「来店の理由を作り、回遊で高単価につなげる」系統。shinjicase では、この2系統を地方百貨店の `hot_spots` の許容条件として持たせる。
