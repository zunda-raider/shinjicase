# お題：コンビニの売上向上施策

地方百貨店と同じ形式で「許容解（最初の5分）」と「完全解（質疑まで）」に分けたもの。完全解では、質疑から加えた部分に〔質疑n〕と付けている。

---

# 許容解：最初の5分の発表

## 6パターンの発表内容

### パターン1：朝の通勤客の客単価（99点）
- **前提**：都市部の住宅街とオフィスが混在する立地の1店舗。主な客層は通勤客と住民。3年で売上20%増（1.2倍）
- **構造化**：売上＝客数×単価×頻度。客数はコンビニという業態上、差別化が難しく伸ばしにくいので、単価を狙う。客層（通勤客／住民）×時間帯（朝昼夜）で分ける
- **ボトルネック**：朝の通勤客。客数は最も多いのに、朝食だけ、コーヒー1杯だけで単価が低い
- **施策**：朝に1,000円以上買うとコーヒーLサイズ無料（まとめ買いで単価を上げ、差別化にもなる）

### パターン2：レジの回転率と住宅向け商品（95点）
- **前提**：1店舗（多店舗・本部の施策は対象外）。立地は都市部の混在エリアで動かせない。3年。年間売上約2億円、日販約55万円。依頼人は店長。レジの構成は自分で置く
- **構造化**：売上＝客数×客単価。客数＝商圏人数×当店の選択率×レジの回転率
- **ボトルネック**：レジの回転率（差別化が難しい中で、混んでいない店が選ばれる）と、住宅客向けの客単価
- **施策**：無人レジの導入（約1年かかる）、日常生活品を前面に出して単価を上げる

### パターン3：朝の通勤客と住民の需要（95点）
- **前提**：特定の1店舗。都市部の混在エリア。主な客層は通勤客と住民。依頼人はFC加盟店
- **構造化**：売上＝客数×客単価。通勤客は朝の朝食需要が多い。住民は朝昼夜にまんべんなく来る
- **ボトルネック**：朝の通勤客の時間の制約と単価の低さ、住民需要を取り込めていないこと
- **施策**：朝のコーヒーと弁当などのセット（単価）、レジの効率化（時間の制約）、日用品の拡充と小容量のラインナップ（住民）

### パターン4：駅前店の来店割合（95点）
- **前提**：自分で仮定してよいかを確認。駅前、24時間営業。0〜6時は1時間50人、6〜18時は100人、18〜24時は50人で計1,800人。客単価1,000円で日販180万円
- **構造化**：売上＝通過人数×来店割合×客単価。通過人数は店側では動かせない
- **ボトルネック**：来店割合と客単価
- **施策**：水やおにぎりの限定割引（必需品のニーズで来店割合を上げる）、東京バナナのような菓子折りの包装サービス（差し入れ需要で単価を上げる）

### パターン5：夕方の住民の買上点数
- **前提**：大手チェーンに加盟する都市部混在エリアの1店舗。3年
- **構造化**：売上＝1日の来店客数×購入率×客単価。購入率はもともと高いので動かさない。朝・昼はオフィスワーカー（単品）、夕方以降は住民（ニーズがさまざま）
- **ボトルネック**：夕方以降の住民の来店頻度と買上点数
- **施策**：弁当、惣菜、冷凍食品、飲料の夕飯セットをアプリで提案し、事前予約・帰宅時受け取りにする。夕方で検証してから朝・昼に広げる

### パターン6：競合の需要を取り込む
- **前提**：都市部混在エリアの1店舗。3年。競合は他チェーン、スーパー、ドラッグストア、ネット通販
- **構造化**：売上＝客数×客単価。客数＝近隣住民数×食事の回数×コンビニ選択率。選択率を上げる方向は「コンビニの需要をより満たす」か「スーパー・ドラッグストアの需要をコンビニで満たす」の2つで、後者を選ぶ（インパクトが大きい）
- **ボトルネック**：スーパー・ドラッグストアから取り込める選択率
- **施策**：健康食と、カット野菜など一人暮らし向けの自炊用食材を置く

# 完全解：質疑まで盛り込んだ版

## 完全解1：朝の通勤客の客単価

**前提**：都市部混在エリアの1店舗。客層は通勤客と住民。3年で売上20%増

**構造化**
```
売上 = 客数 × 単価 × 頻度
  └ 客層（通勤客／住民）× 時間帯（朝／昼／夜）
  └ 朝の実際の客数 ← レジの回転率（レジ台数 × 稼働率）   〔質疑2〕
```
- 最も解くべき課題：朝のピーク時の客数に対して単価が低いこと。それを支える回転率〔質疑3〕

**施策**
| 施策 | 中身 |
|---|---|
| A 朝食とコーヒーのセット特典 | 1,000円以上の購入でコーヒーL無料。コーヒーの原価は1杯20円程度なので、単価の上昇で回収できる〔質疑1〕 |
| B もう1品をレジ前に | ホットスナックの声かけ、夏はスポーツドリンクを店頭に、冷感シートをレジ前に〔質疑1〕 |
| C 回転率の確保 | オペレーションの再確認、マニュアルの整備。混雑に応じてセルフレジを追加する（本部の補助も活用）〔質疑2・3〕 |
| D 競合への差別化 | 他のコンビニには、コーヒー特典と商品配置（お酒の近くにおつまみ、タバコの近くにライター、右回りの導線）で差をつける。カフェには、コーヒーとパンなどの朝食を一緒に選べる強みで対抗する〔質疑4〕 |
| E 夜のセット特典 | 1,200円以上の購入でデザート1品無料〔質疑5〕 |
| F アレンジレシピの掲示 | 例：チャーハン×チーズ。まとめ買いを促す〔質疑5〕 |
| G 別の方向性 | 法人向けの定期配達。週ごとにカタログを渡し、決まった曜日に配達して手数料を取る〔質疑6〕 |

**KPIと撤退基準**：施策前と比べた売上の増加率、朝の時間帯の売上増加率、客単価。既存の利益を損なっていれば撤退する〔質疑1〕。レジに余裕がある（例：2台で稼働率100%と50%）場合ほど、実現性とインパクトが高い〔質疑2〕。

## 完全解2：住宅向け商品と、レジの回転率

**前提**：1店舗。立地は都市部の混在エリアで動かせない。3年。年間売上約2億円、日販約55万円。依頼人は店長

**構造化**
```
売上 = 客数 × 客単価
  ├ 客数 = 商圏人数 × 当店の選択率 × レジの回転率
  │     └ 選択率 ← リピート                         〔質疑5〕
  └ 客単価 ← 品揃えがオフィス寄りで、住宅客の需要を取り込めていない   〔質疑2〕
```
- 最も解くべき課題：**客単価**。品揃えがオフィス寄りになっていて、住宅街の潜在的な需要を取り込めていない〔質疑2〕

**施策**
| 施策 | 中身 |
|---|---|
| A 家庭向け商品を前面に出す（最優先） | グループで扱っている生活用品を入口付近やレジ前に置く。コストがほぼかからない〔質疑1〕 |
| B 両方のニーズを1店で満たす | オフィス寄り・住宅寄りの特化型コンビニが多い中で、両方を満たせば差別化になる。生活用品をクロスセルやセット販売で売る〔質疑3〕 |
| C 店内のゾーニング | 家庭用品、ビジネス用品、両方に使える食品や水の3つのエリアに分ける〔質疑4〕 |
| D ポイント・クーポン | 同じ店を繰り返し使うと特典が当たりやすくなる、割引がもらえる仕組みでリピートを作る〔質疑5〕 |
| E 無人レジの導入 | コストと時間がかかるので後回しにする〔質疑1〕 |

## 完全解3：朝の通勤客を最優先に、住民はスモールスタート

**前提**：特定の1店舗。都市部の混在エリア。客層は通勤客と住民。依頼人はFC加盟店

**構造化**
```
売上 = 客数 × 客単価
  ├ 通勤客：朝に集中。昼は会社、夜は自宅や外食で来店が限られる   〔質疑6〕
  ├ 住民：一日を通して需要が見えにくい
  ├ 客数 ← 来店頻度（セット販売や品揃えの拡充で伸ばせる）       〔質疑4〕
  └ 客単価 ← 1回あたりの点数（朝の通勤客で最も伸びしろがある）   〔質疑3〕
```
- 最も解くべき課題：**朝の通勤客の時間の制約と単価の低さ**〔質疑1〕

**施策**
| 施策 | 中身 |
|---|---|
| A 朝のセット | コーヒーと弁当などのセットで、朝ごはんがすぐ揃うようにする。既存の商品で始められる〔質疑1〕。顧客のロイヤリティも高め、来店頻度にも効く〔質疑4〕 |
| B レジの効率化 | 朝の時間の制約に応える |
| C 日用品・小容量の拡充 | 住民の需要に応える。新たな投資が必要なので中長期の施策〔質疑1〕 |
| D 八百屋的な生鮮ラインナップ | 2〜3年の時間軸ならスモールスタートで始める〔質疑2〕。スーパーから客を引き込み、来店頻度を上げる〔質疑4〕 |

**優先順位**：通勤客の施策が最優先。2〜3年の時間軸にしても変わらない〔質疑1・2〕。

## 完全解4：駅前店の来店割合

**前提**：駅前、24時間営業。1日1,800人×客単価1,000円＝日販180万円。客層は学生と社会人が中心と仮定

**構造化**
```
売上 = 通過人数 × 来店割合 × 客単価
  ├ 通過人数：約1万人。動かせない
  └ 来店割合：現状18%                                         〔質疑3〕
        ├ 顧客側の要因：必需品のニーズ（水・食べ物・傘・タバコ）     〔質疑5〕
        │              好奇心（店外から見える仕掛け）              〔質疑6〕
        └ 外部の要因：天候（夕立で傘が必要になる）                 〔質疑4〕
```
- 最も重要な要素：**来店割合**。駅前は通過人数が多いので、来店割合が上がれば得られる客数が大きい〔質疑3〕

**施策**
| 施策 | Impact | コスト | 中身 |
|---|---|---|---|
| A 水・おにぎりの限定割引（最優先） | ◎ | ○ | 張り紙で告知する。必需品を求める学生や社会人に刺さる〔質疑1〕 |
| B 菓子折りの包装サービス | △ | △ | 差し入れ需要を持つ客は多くない。包装の手間とコーナーの設置が必要〔質疑1〕 |
| C 喫煙所の設置 | | | 喫煙所のない駅が増えているので、喫煙者が立ち寄る。タバコやコーヒーの購入につながる〔質疑4〕 |
| D ガチャガチャやクレーンゲーム | | | 店外から見えるように置き、好奇心で来店を促す〔質疑6〕 |

**試算**：来店割合が18%から30%になれば、来店客数は1,200人増えて＋120万円〔質疑3〕。

**最も不確かな前提**：駅の利用者が本当に学生と社会人中心か。高齢者が多い駅なら、必需品の施策は効きにくい〔質疑2〕。

## 完全解5：夕方の住民の買上点数

**前提**：大手チェーンに加盟する都市部混在エリアの1店舗。3年

**構造化**
```
売上 = 来店客数 × 購入率 × 客単価
  ├ 購入率：もともと高い
  ├ 来店客数 = 既存顧客 × 来店頻度
  └ 客単価 = 買上点数 × 単価
        └ 夕方の住民の点数 = いつもの点数 ＋ 増分（翌朝用・デザート）   〔質疑2〕
```
- 主に狙う効果：**買上点数**。夕方にすでに来ている客なので、短期の売上に反映しやすい。来店頻度は習慣づけに時間がかかるので後に回す〔質疑1〕
- コンビニの強み：帰宅途中に、翌朝の分まで短時間でまとめて買えること〔質疑3〕

**施策**
| 施策 | 中身 |
|---|---|
| A 夕飯セットの事前予約 | アプリで提案し、帰宅時に受け取れるようにする |
| B 純粋な追加購入を作る | 主商品は値引きしない。普段の点数を超えたときだけ特典をつける。弁当だけの客には翌朝用のパン、コーヒー、デザートを提案する〔質疑2〕 |
| C 行動にもとづく提案 | 属性は推定せず、購買行動だけで提案する。提案理由を過去の購入との組み合わせとして見せ、オプトアウトもできるようにする〔質疑3・4〕 |
| D 反応しない客には止める | クリック率、追加購入率、客単価の増分を見て、反応がなければ表示を減らすか止める〔質疑5〕 |
| E 段階的な展開 | 夕方で検証し、朝・昼に広げる |

**効果の測り方**：KPIは顧客ごとの増分点数と増分売上〔質疑2〕。似た客をランダムに2群に分け、表示した群と表示しない群の差で純粋な効果を測る（例：1,050円と1,000円なら50円）。数週間〜数か月で比較し、前倒し購入や他商品の減少も確認する。最終指標は増分粗利〔質疑6〕。

## 完全解6：競合の需要を取り込む

**前提**：都市部混在エリアの1店舗。3年。競合は他チェーン、スーパー、ドラッグストア、ネット通販

**構造化**
```
売上 = 客数 × 客単価
  └ 客数 = 近隣住民数 × 食事の回数 × コンビニ選択率
        └ 選択率 ← スーパー・ドラッグストアから取り込む需要
              ├ 取り込む相手：単身・共働き世帯（ある程度の金銭的余裕がある）   〔質疑5・6〕
              └ 選ばれる理由：一人分の量／冷蔵庫を圧迫しない／余らせない／手軽さ  〔質疑4・6〕
```
- 既存客を狙わない理由：コンビニの需要がある住民はすでに通っていて、頻度も単価も伸びしろが小さい〔質疑1〕

**施策**
| 施策 | 中身 |
|---|---|
| A 健康食・自炊用食材 | 一人が一食で食べきれる量のカット野菜や肉、健康食を置く〔質疑4〕 |
| B 「行けば何でも揃う」認識を作る | 自炊用食材、健康食、化粧品を揃え、まずコンビニに行き、足りないものだけ他店で買う行動に変える〔質疑2〕 |
| C 雑誌売場の置き換え | オンライン化で需要が減った雑誌の棚を縮小し、食材と健康食を置く〔質疑3〕 |

**規模の根拠**：単身、共働き、夫婦二人の世帯が増え、少量の食材の需要は広がっている〔質疑5〕。

## コンビニの突っ込みパターン（6件から）

| パターン | 例 |
|---|---|
| 実現性・制約 | 朝のピークにセット特典を回せるか（完全解1） |
| 課題を1つに絞る | 最も解くべき課題は何か（1・2・3） |
| 二択・優先順位 | 点数と頻度のどちらか、どの施策から始めるか（2・3・5） |
| 前提への反証 | 客層が固定なら頻度も伸びないのか（3）、最も不確かな前提は（4） |
| 純増かどうか | セットへの置き換えにすぎないのでは（5） |
| リスク | 個人情報、推定の誤り（5） |
| 効果の測り方 | 表示しなくても買っていた分をどう切り分けるか（5） |
| 売場面積のトレードオフ | 棚を削ると既存売上が落ちないか（6） |
| 価格差を超える理由 | スーパーより割高でも選ばれるか（6） |
| 別の方向性 | 既存の打ち手が使えないなら何をするか（1・2） |
